# Entrega E1 · Observatorio de Rentabilidad para Repartidores (Gig Economy Colima)
Equipo: Fernando Benavides Manzo, Milagros Andrade · Etiqueta: e1 · Tablero: https://github.com/23460503-sudo/observatorio-gig

## Resumen en tres líneas
Se implementó un pipeline automatizado de extremo a extremo que integra datos meteorológicos de Open-Meteo con registros transaccionales de plataformas de Gig Economy en Colima y Villa de Álvarez, validando los datos con una Puerta de Calidad Pandera y cuarentena documentada.
Se completó el modelado de pronóstico de series de tiempo comparando cuatro familias (SES, Holt, Holt-Winters y ARIMA), seleccionando el modelo ganador por menor error de prueba (Holt-Winters, MAPE: 36.02%) y verificando ausencia de autocorrelación en residuos mediante la prueba de Ljung-Box ($p = 0.9435$).
Se formalizó el aseguramiento de calidad con un Plan SQA bajo norma IEEE 730, especificación de requerimientos verificables, integración continua (CI) en GitHub Actions con 7 pruebas unitarias automatizadas (`pytest`), auditoría de seguridad y medición empírica de disponibilidad ($A = 99.43\%$, superando el objetivo del 95%).
